# Консольная игра висилица

## Описание проект

### Игра висилица, в которой есть 2 режима - интерактивный и нет(без взаимодействия с пользователем), интерактивный при начинается при запуске игры без аргументов командной строки. В интерактивном режиме игра идет до тех пор пока либо игрок не отгадает слово, либо не закончатся попытки и не нарисуется висилица окончательно.

## Интерактивный режим:
### В интерактивном режиме пользователь должен угадывать случайное слово из случайной категории(заранее определеы как и слова) при случайной сложности игры(всего существует 3 - hard, medium, easy)(сложность можно задать аргументом командной строки). В зависимости от заданной сложности игры у игрока есть разное количество попыток ошибиться, чем сложнее уровень, тем меньше попыток. При неугадывании рисуется висилица. 

## Неинтерактивный режим:
### Вводится загаданное слово и слово которое пользователь считает угаданным, если пользователь угадал, то рисуется слово, иначе загаданное слово с '*' на местах неотгаданных букв.

### В игре существует механизм подсказки, он выдает предложение, которое описывает загаданное слово, например, загаданное слово - "бабушка", подсказка будет - "член семьи, родитель твоего родителя", что-то похожее.
